PERSONAL BACKUP INTEGRATION

Privacy policy

Effective October 22, 2026

Backup KulAhidi is a personally operated backup workflow for the Kül Ahidi game development project. Restic prepares encrypted backups on the owner's computer; Rclone transfers the encrypted backups to a Google Drive account authorized by the owner. This informational website does not provide cloud storage, account sign-in or a third-party backup service.

Information accessed and purpose

The local Rclone application requests Google Drive API permissions to list and manage the backup repository's files, create and upload encrypted backup data, verify stored objects and retrieve backup files during restoration. Depending on the granted scope, Rclone may technically access other Drive files, but the intended workflow is confined to the owner's designated backup repository.

Data use and storage

Restic encrypts the selected local project files before upload. Backup repository objects are stored in the owner's Google Drive. Authentication credentials and refresh tokens are held in the owner's local Rclone configuration; the Restic repository password is managed separately by the owner. None are requested by this website. The website does not collect or receive Google Drive files, tokens, backup passwords or account information.

Sharing and advertising

The backup workflow does not sell, share with advertisers, or use Google user data for advertising. Data is transferred only as needed to provide the owner's requested backup and restore functions. GitHub Pages hosts this public informational website and may process ordinary hosting logs under its own policies. The website has no analytics, ads, tracking scripts or account forms.

Retention, deletion and revocation

The owner determines how long backup snapshots are retained using Restic and can delete the repository's encrypted objects from Google Drive. Google account access can be revoked at Google Account connections. Revoking access does not automatically delete backups already uploaded.

Limited use

Google API user data is used only for the owner's requested backup and restoration functionality. The intended use follows the Google API Services User Data Policy, including its Limited Use requirements. No unrelated processing or profiling is performed.

Contact and policy changes

Questions can be directed to the maintainer through the GitHub profile. This page will be updated if the tools, data handling or Google Drive permission model materially changes.

Google authorization takes place in the local Rclone application, never through this website.
