PERSONAL BACKUP UTILITY

Private backups.
Reliable recovery.

Backup KulAhidi is a personal backup workflow for the Kül Ahidi game development project. It uses Restic for encrypted, versioned backups and Rclone to transfer the encrypted repository to the owner's Google Drive.

This site is for information only. There is no sign-in, file upload portal or online account service here. Google Drive authentication happens locally through Rclone.

01 · Encrypt

Restic reads selected project folders and encrypts backup content on the owner's computer.

02 · Back up

Rclone uses authorized Google Drive access to store and retrieve encrypted repository objects.

03 · Restore

The owner can recover files from prior backup snapshots using Restic and a separately held password.

Why Google Drive permission?

Rclone needs Drive access to create, list, update and retrieve backup repository files. This authorization is for the owner's personal use and can be revoked from Google Account connections.

Learn how data is used and protected in the privacy policy.
